# The Mansion

Um jogo de sobrevivência e terror em texto desenvolvido em Python.

---

## Funcionalidades

* Sistema de escolhas
* Narrativa interativa
* Exploração da mansão
* Sistema de vida
* Sistema de inventário
* Sistema de combate
* Personagens com diálogos próprios
* Inimigos com comportamentos básicos
* Eventos com elementos aleatórios
* Estrutura baseada em Programação Orientada a Objetos (POO)

---

## Planejamento

* Novas salas exploráveis
* Novos inimigos
* Eventos aleatórios adicionais
* Sistema de armas de fogo
* Múltiplos finais
* Sistema de salvamento de progresso
