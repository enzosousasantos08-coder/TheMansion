# The Mansion
Um jogo de sobrevivencia e terror em texto escrito em Python

## Sobre o jogo
Voce e seu grupo de agentes estavam fugindo de criaturas desconhecidas em uma floresta.
sem opções, acabaram entrando em uma mansão enorme para se proteger.

Mas a mansão guarda muitos segredos e perigos, e cada escolha pode mudar o destino de seu grupo

## Funcionalidades atuais

- Sistema de escolhas
- Introdução narrativa
- Exploração inicial da mansão

## Futuras atualizações

- Sistema de inventário
- Vida e status do jogador
- Mais salas exploráveis
- Personagens com histórias próprias
- Inimigos e eventos aleatórios
- Múltiplos finais
